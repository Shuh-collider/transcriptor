# Транскриптор

[English version](README.md)

Расшифровка видео с YouTube на вашем компьютере. Вставьте ссылку на видео, плейлист или целый канал и получите:

- **расшифровку** с таймкодами — речь распознаётся на вашей видеокарте NVIDIA (GigaAM v3 для русского, Qwen3-ASR для английского и ещё 28 языков);
- **кто говорит** — спикеры размечаются автоматически, им можно дать имена;
- **надписи на экране** (по желанию) — слайды, подписи, промпты и код из видео читает Gemini;
- **пересказ с главами** от Gemini или Claude, с кликабельными таймкодами;
- выгрузку в TXT, Markdown и JSON и **MCP-сервер**, через который Claude и другие ИИ-ассистенты ставят видео в очередь, читают расшифровки и ищут по ним.

Интерфейс на английском и русском (переключатель EN | RU вверху). Всё, кроме пересказа и надписей на экране, работает локально.

## Установка (Windows)

Откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/Shuh-collider/transcriptor/main/install.ps1 | iex
```

Установщик:

1. скачает Транскриптор в `%USERPROFILE%\transcriptor` (через git, если он есть, иначе архивом);
2. поставит [uv](https://docs.astral.sh/uv/) — он сам скачает Python 3.11;
3. **определит видеокарту** и поставит подходящую сборку PyTorch:

   | Видеокарта | Сборка PyTorch |
   |---|---|
   | NVIDIA GTX 16xx, RTX 20xx / 30xx / 40xx / 50xx и новее | CUDA 12.8 |
   | Старые NVIDIA: GTX 9xx / 10xx | CUDA 12.6 |
   | Нет NVIDIA (AMD, Intel, без видеокарты) | процессор — работает, но в разы медленнее |

4. создаст `.env` для ключей и ярлык **Transcriptor** на рабочем столе.

Первая установка скачивает около 5 ГБ пакетов, модели распознавания (около 7 ГБ) скачаются при первой расшифровке. **Чтобы обновить, выполните ту же команду ещё раз.**

Настройки (задать перед командой): `$env:TRANSCRIPTOR_DIR = "D:\transcriptor"` — папка установки, `$env:TRANSCRIPTOR_TORCH = "cpu"` (или `cu126`, `cu128`) — выбрать сборку вручную, `$env:TRANSCRIPTOR_NO_SHORTCUT = "1"` — без ярлыка.

Уже скачали код? Запустите `install.bat` в его папке.

**Что нужно:** Windows 10/11 64-бит, видеокарта NVIDIA от 8 ГБ памяти (работает и на процессоре), около 15 ГБ свободного места.

## Ключи (по желанию, бесплатно)

Расшифровка работает без ключей. Ключи открывают остальное — впишите их в `.env` в папке установки, сервер подхватит их без перезапуска.

| Строка в `.env` | Зачем | Где взять |
|---|---|---|
| `HF_TOKEN=hf_…` | Кто говорит (pyannote) | Примите условия на [странице модели](https://huggingface.co/pyannote/speaker-diarization-community-1), затем создайте токен **Read** в [настройках Hugging Face](https://huggingface.co/settings/tokens) |
| `GEMINI_API_KEY=…` | Пересказ, главы и надписи на экране (есть бесплатный тариф) | [Google AI Studio](https://aistudio.google.com/apikey) |
| `ANTHROPIC_API_KEY=sk-ant-…` | Пересказ через Claude | [Консоль Anthropic](https://console.anthropic.com/settings/keys) |

Для пересказа достаточно одного ключа. Для надписей на экране нужен ключ Gemini.

## Работа

Дважды щёлкните ярлык **Transcriptor** (или `start.bat`) — браузер откроет http://127.0.0.1:8000.

1. Вставьте одну или несколько ссылок: видео, Shorts, плейлисты, каналы. Из плейлистов и каналов видео выбираются галочками.
2. Выберите настройки: язык видео (по умолчанию авто), спикеры, **Читать надписи на экране**, модель и язык пересказа.
3. Нажмите **Расшифровать**. Видео обрабатываются по одному; 30 минут видео — 1–2 минуты на RTX 3080 Ti.
4. Читайте пересказ и главы, переходите к любому моменту во встроенном плеере, ищите по тексту, подписывайте спикеров, выгружайте файлы.

### Надписи на экране

Включайте **Читать надписи на экране** для видео, где главное — на экране: демо, слайды, записи экрана, клипы с подписями. Транскриптор скачивает картинку (до 720p, без звука), берёт кадр при каждой смене картинки и раз в секунду, склеивает похожие кадры в «экраны» и от каждого берёт **последний** кадр — на нём текст, который печатается или появляется по строчкам, уже целиком. Gemini выписывает только новый текст, и он попадает в расшифровку строками «На экране» и в пересказ. Работает параллельно с распознаванием речи; видео на 25 минут — несколько минут и расход лимита Gemini.

## Подключение ИИ-ассистентов (MCP)

Транскриптор — MCP-сервер: Claude, Cursor и другие MCP-клиенты сами ставят видео в очередь, ждут результат, читают расшифровки и ищут по ним. Список инструментов — в [английском README](README.md#connect-ai-assistants-mcp).

В примерах замените `C:\Users\you\transcriptor` на папку установки.

**Claude Desktop:** «Настройки → Разработчик → Изменить конфигурацию», добавьте в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "transcriptor": {
      "command": "C:\\Users\\you\\transcriptor\\.venv\\Scripts\\python.exe",
      "args": ["C:\\Users\\you\\transcriptor\\transcriptor_mcp.py"]
    }
  }
}
```

**Claude Code:**

```bash
claude mcp add transcriptor -- "C:\Users\you\transcriptor\.venv\Scripts\python.exe" "C:\Users\you\transcriptor\transcriptor_mcp.py"
```

**Клиенты с поддержкой HTTP** (Cursor и другие): пока приложение запущено, MCP доступен по адресу `http://127.0.0.1:8000/mcp`.

Если веб-сервер не запущен, MCP поднимает его сам — фоном, лог в `data/server.log`. Такой сервер закрывается вместе с MCP-клиентом; чтобы он работал постоянно, запускайте приложение ярлыком.

## Консольный режим

```bash
.venv\Scripts\python.exe -m transcriptor run "https://youtu.be/VIDEO_ID"
```

Параметры: `--lang ru|en`, `--speakers 2` (точное число спикеров), `--no-speakers`, `--screen` (надписи на экране), `--no-summary`, `--model claude-sonnet-5`, `--summary-lang same|en|ru`, `--engine qwen`. Ссылки на плейлисты и каналы обрабатываются целиком.

## Где результаты

`data/videos/<id видео>/`: звук, `transcript.json` (все слова с таймкодами, надписи, пересказ), `video.json` (метаданные), `frames/` (кадры для надписей). Кнопки в интерфейсе выгружают TXT, Markdown и JSON.

## Если что-то не работает

- **«YouTube просит подтвердить, что вы не бот»**: впишите в `.env` строку `YTDLP_COOKIES_FROM_BROWSER=firefox` (или `chrome`, `edge`) — браузер, где вы вошли в YouTube. Иногда проходит само через некоторое время.
- **Ошибка 403 или очень медленное скачивание**: Транскриптор повторяет загрузку через IPv4 и сам переходит на IPv4, если IPv6 до YouTube не работает. Если не помогло, обновите yt-dlp: `uv lock --upgrade-package yt-dlp` и снова запустите установщик.
- **Видеокарта не используется** (вверху «Нет видеокарты»): обновите драйвер NVIDIA и снова запустите установщик.
- **Ошибки сертификатов**: HTTPS проверяется через хранилище сертификатов Windows (`truststore`), поэтому антивирус или прокси, подменяющие сертификаты, не мешают.
